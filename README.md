# Blades & Banners: Two Fronts

An original, complete browser action-strategy game. Fight enemies manually on the upper ridge to fund six classes of automatically fighting troops in the valley. Five campaign battles, four hero enemy classes, six opposing army classes, a final commander, permanent upgrades, local saves, original illustrated vector art, original synthesized sound and music.

## Run

Requires Node.js 24 and npm (matching the shared publishing workflow).

```sh
npm ci
npm run dev
```

Open the Vite URL. Production: `npm run build`; static output is `dist/`. Inspect it with `npm run preview`. `base: './'` supports subdirectory hosting and iframe embedding. No backend or runtime services.

## Controls

WASD/arrows: move and face. Space: sword attack. Left-click the ridge: aim and attack. Shift: dodge. 1–6 or click recruitment cards: recruit. Escape: pause. Touch: left joystick, right attack/dodge buttons, tap cards. Portrait and landscape supported, landscape recommended.

## Verification

`npm test` checks deterministic combat, targeting, projectiles, healing, shield interception, siege, economy, all five campaign levels, progression and persistence, plus menu/input integration in a DOM harness. `npm run build` checks production compilation. `npm run cover` recreates the original 960×600 catalog art. Detailed limits and results: `docs/verification.md`.

## Publishing

Created using https://github.com/procrastinate-games/game-template. Preserve `.github/workflows/publish.yml`. Before pushing main run:

```sh
npm test
npm run build
npx --yes github:procrastinate-games/game-publisher#v1
```

The shared platform workflow publishes to `https://pg-blades-and-banners-two-fronts.register-c02.workers.dev/` after the separate organization repository is created and source is pushed. That URL is an expected address, not evidence of deployment.

## Artwork, audio and licensing

All character, portrait, terrain, UI and cover artwork is generated by original drawing code in `src/render.js` and `scripts/cover.mjs`. Sound and music are original synthesized compositions in `src/audio.js`. No reference-game artwork, characters, audio or code is included. Fonts use the browser's local serif and system families; the game makes no external asset requests.

Inspired by the two-front loop of Battle for Gondor (2005) and the direct action feedback of Prince of War (2006). Setting, characters, art, code and identity are original.
